# Le Pin — QR-меню

Мобильная страница меню ресторана и бара Le Pin: вкладки Кухня / Бар, категории, переключатель РУС / ҚАЗ, тёмная тема.

## Структура

```
qr-menu/
├── index.html        — каркас страницы
├── css/style.css     — стили (mobile-first)
├── js/menu.js        — загрузка menu.json и отрисовка
├── data/menu.json    — ВСЁ меню: названия, цены, объёмы
└── img/logo.png      — логотип
```

## Как запустить у себя

`fetch()` не работает, если открыть `index.html` двойным кликом (адрес `file://`).
Нужен локальный сервер: в VS Code установи расширение **Live Server** → правый клик по `index.html` → *Open with Live Server*.

## Как поменять цену или блюдо

Только в `data/menu.json`. Пример позиции:

```json
{
  "name": { "ru": "Шакшука с чиабаттой", "kk": "Чиабатта мен шакшука" },
  "desc": { "ru": "Состав блюда" },
  "size": "350 мл",
  "price": 3950,
  "tag": "signature"
}
```

- `kk` и `desc` — необязательные. Если казахского текста нет, покажется русский.
- `price: null` — вместо цены будет «уточняйте».
- `tag: "signature"` — плашка «фирменный».

## Публикация на GitHub Pages

1. Залей папку в репозиторий (например, `lepin-menu`).
2. Settings → Pages → Branch: `main`, папка `/root` → Save.
3. Через минуту меню доступно по адресу `https://<логин>.github.io/lepin-menu/`.
4. Сделай QR-код на этот адрес (лучше в SVG для печати).
